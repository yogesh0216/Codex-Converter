## 🚀 Key Features

- **Multi-Format Transformation:** Real-time bi-directional conversion between standard text and raw machine representations.
- **Clean Interface:** Minimalist, intuitive input/output flow designed for quick debugging and payload analysis.
- **Copy to Clipboard:** One-tap export for rapid analyst workflows.
- **Lightweight & Dependency-Free:** High-performance conversion logic with zero unnecessary overhead.

## 🔄 Supported Encodings

| Format | Direction | Example Input | Example Output |
|---|---|---|---|
| **Binary** | Text ⇄ 8-bit Bin | `SOS` | `01010011 01001111 01010011` |
| **Hexadecimal** | Text ⇄ Hex | `Admin` | `41 64 6d 69 6e` |
| **Morse Code** | Text ⇄ Morse | `HELLO` | `.... . .-.. .-.. ---` |
| **Base64** | Text ⇄ Base64 | `secret_token` | `c2VjcmV0X3Rva2Vu` |
